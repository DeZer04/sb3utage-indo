Patcher Dolphin

Patcher ini membuat folder Riivolution berisi terjemahan dari game milikmu sendiri dan file patch SB3 UTAGE:INDO. Dolphin memakainya lewat menu Start with Riivolution Patches, jadi game aslinya tidak diubah. Semua diproses di komputermu; tidak ada file yang diunggah.

Browser ini tidak bisa menulis ke folder. Buka halaman ini di Chrome atau Edge versi baru di PC (Windows, Linux, atau macOS).
1

File patch

Unduh salah satu patch dari GitHub, lalu pilih file .patch-nya di sini.

Full Patch Indo (seluruh game, termasuk grafis) · Deskripsi Only (hanya deskripsi)

2

Folder game hasil ekstrak

Ekstrak game Sengoku BASARA 3 Utage (Jepang, S3HJ08) milikmu di Dolphin:

  1. Klik kanan game › Properties › tab Filesystem.
  2. Klik kanan baris paling atas (Disc) › Extract Entire Disc… › pilih folder kosong.
  3. Di sini, pilih folder itu (atau folder DATA di dalamnya).
3

Folder Riivolution Dolphin

Di Dolphin: File › Open User Folder, buka folder Load, lalu buat folder Riivolution kalau belum ada. Pilih folder Riivolution itu di sini. Butuh ruang kosong sekitar 1,1 GB untuk Full Patch.

4

Pasang

Patch terpasang

  1. Di Dolphin, klik kanan game › Start with Riivolution Patches…
  2. Pastikan patch SB3 UTAGE:INDO aktif, lalu tekan Start.
  3. Untuk main versi Jepang asli, jalankan game seperti biasa (tanpa Riivolution).

Mengganti patch (misalnya dari Deskripsi Only ke Full): jalankan patcher lagi dengan file patch lain ke folder yang sama.

Patcher memeriksa setiap file game dengan checksum SHA-1. Kalau ada yang berbeda, berarti dump-nya bukan S3HJ08 asli atau sudah dimodifikasi, dan patcher berhenti tanpa merusak game.
